# Chatbot
AI chatbot built using Python combining LSTM (TensorFlow/Keras) with GloVe embeddings and NLP preprocessing. Integrates Google Gemini API and Wikipedia for enhanced responses. Trained on Cornell Movie Dialogs dataset to generate human-like conversations with hybrid AI intelligence.
Python chatbot that uses Google Gemini for complex queries and Wikipedia for real-time information. Combines NLP and ML techniques to deliver accurate, human-like conversational responses.
Make sure to use Gemini API key. Create one and paste the key in key option.
